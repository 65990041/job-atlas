# Job Atlas Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Build a private, responsive Thai job comparison site with a list, detail view, and location map for all 55 supplied announcements.

**Architecture:** Extract a reviewed static JSON dataset from the supplied ZIP. React renders filtered list, map, and detail views from one data source. Personal statuses and notes stay in each browser's local storage; original PDFs are not deployed.

**Tech Stack:** Python/PyMuPDF for extraction; React, Vite, Leaflet, Vitest for site and checks.

**Spec:** https://app.notion.com/p/41d2ae5e9de481e08bedeae248937e32

## Global Constraints

- User interface in Thai, with warm off-white background, dark text, and muted green accent.
- Keep the Site owner-private; do not publish PDFs or personal notes.
- Display source file, last reviewed date, and location precision for each offer.
- Never infer application-open status from a PDF close date alone.
- Unknown or multi-site locations must not appear as precise building pins.

## Review Focus

- Missing PDF fields display as unknown rather than becoming plausible invented values.
- Multi-site announcements retain all stated sites and show the ambiguity.
- Salary base and total monthly income remain separate.
- Filters produce the same offer set in the list and map.
- Browser-local notes and statuses do not enter the deployable dataset.
